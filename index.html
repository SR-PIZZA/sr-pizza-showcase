📐 Clean Architecture Feature-First en Flutter (Módulo Domicilios)

1. Capa de Dominio (Domain)

Dart puro (Zero dependencias de UI)

  • 📄 Entities: Order, OrderItem, OrderStatus, DriverTracking
  • 📜 Repositories: IOrderRepository, IDriverTrackingRepository
  • 🎯 Use Cases: WatchOrderStatusStream, TransitionOrderStatus

2. Capa de Datos (Data)

APIs REST, WebSockets y caché local

  • 🌐 Remote DataSource: REST API (Dio)
  • ⚡ WebSocket DataSource: Socket.io en tiempo real
  • 💾 Local DataSource: Hive / SQLite offline

3. Capa de Presentación

Widgets y BLoC / Riverpod

  • 🧠 BLoC: OrderLifecycleBloc, LiveMapCubit
  • 📱 Widgets: StatusStepperWidget, DriverLiveMapView
  • 🖥️ Screens: OrderTrackingScreen, ActiveDeliveriesKanban
